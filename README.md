# 📚 Project Description

This project is a C++ application created as a school team assignment.

The application demonstrates:
- C++ programming concepts
- Object-oriented programming
- Team collaboration using GitHub
- Application logic and data management

The project was developed by a team of 4 students.

---

# ⚙️ Installation & Running

## Clone the repository

```bash
git clone https://github.com/BSAndrikov24/BookFlow.git
```

## Open the project folder

```bash
cd BookFlow
```

## Run the project

Open `BookFlow.slnx` in Visual Studio and run the program.
